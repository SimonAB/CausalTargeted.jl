Super Learner & schemas

Super Learner ensemble fitting, candidate libraries, small-n profile helpers, cross-fitted nuisance models, fold-stable covariate schemas, and typed estimand structures.

Categorical adjustment variables are handled automatically across g-computation, LMTP (Gaussian, classification, and hybrid density ratios), LMTP fold-cache, sequential LMTP, survival LMTP, repeated-outcome MSM, and missing-data nuisance pathways. Numeric, Bool, String, and explicit categorical-array columns may be passed without manual dummy coding. A stable internal numeric representation is fitted on the cleaned analysis data and reused across folds. Integer columns are treated as numeric unless explicitly converted to categorical.

Metalearners include :nnls (default for Gaussian), :nnloglik (default for binomial), :cv_selector (discrete Super Learner; alias :winner), and :invmse (:discrete is a deprecated alias for :nnls). Opt-in tree learners :randomforest and :xgboost require loading MLJDecisionTreeInterface and MLJXGBoostInterface (see Methods and estimators).

CausalTargeted.fit_super_learner — Function
fit_super_learner(X, y; learners, metalearner, folds, rng, family) -> SuperLearnerFit

Fit candidate learners and combine with a metalearner.

  • :nnls — cross-validated nonnegative least squares, normalised to simplex weights with a same-prediction squared-loss check that falls back to the best single candidate when normalisation worsens the blend (default for family=:gaussian). This package-specific version is not equivalent to R SuperLearner::method.NNLS or sl3 Lrnr_nnls.
  • :nnloglik — nonnegative Bernoulli (or multinomial) log-likelihood on the logit / probability simplex (default for family=:binomial; R method.NNloglik)
  • :cv_selector — discrete Super Learner: one-hot on the CV-best candidate (Phillips dSL / sl3 Lrnr_cv_selector). Alias: :winner. Candidates may include nested_sl_candidate ensembles (eSL-inside-dSL).
  • :invmse — inverse training MSE weights (fast fallback; LMTP classifiers)
  • :discrete — deprecated alias of :nnls (will become :cv_selector in 0.4)

The NNloglik prediction rule for binary outcomes is logistic(sum(w[j] * logit(p[j]))), not an arithmetic mean of probabilities. It is independently implemented from the same statistical construction as R SuperLearner::method.NNloglik, which can serve as an external numerical QC benchmark.

Squared error remains a proper scoring rule for binary probabilities; NNloglik is an alternative rather than a universally superior criterion. Its stronger penalty for overconfident errors can be useful when fitted probabilities feed propensity scores, density ratios, censoring or missingness models, or other odds-sensitive calculations.

CausalTargeted.adaptive_learners — Function
adaptive_learners(n; rich=false, include_sieve=false) -> Tuple

Cross-validated library selection by sample size:

  • Always includes :mean
  • Adds :glm when n ≥ 12
  • Adds :glmnet when n ≥ 20 and MLJ / MLJLinearModels are loaded
  • Adds :evotree when n ≥ 40 and EvoTrees is loaded
  • Adds rich glmnet variants / deep trees when rich && n ≥ 80 (if extensions loaded)
  • Optional :sieve placeholder flag (include_sieve) maps to extra glmnet α variants when n ≥ 100 (lightweight HAL-like expansion without a HAL dependency)

Neural learners (:mlj_mlp, :mlj_nn_binary) and optional MLJ trees (:randomforest, :xgboost) are never included here — request them explicitly (or pass RICH_SL_LEARNERS, which includes :randomforest) after loading the matching weakdeps. :xgboost remains opt-in even for rich grids because EvoTrees already supplies boosting.

CausalTargeted.crossfit_indices — Function
crossfit_indices(n, folds, rng; cluster=nothing) -> Vector{Vector{Int}}

cluster === nothing: pseudo-random permutation into folds (minimum 2) nearly equal-sized index groups.

cluster given: assign whole clusters to folds (at least two distinct cluster ids required); balances fold sizes by greedily placing sorted-by-size cluster index lists into the currently smallest fold. Test indices for one fold are each returned vector; training rows are the complement across folds.

Covariate schemas & design matrices

CausalTargeted.CovariateSchema — Type
CovariateSchema

Fitted representation of an ordered covariate list. terms are StatsModels terms with categorical levels and dummy contrasts learned from the schema-fit data. The schema defines columns only; it does not impute, standardise, select, or otherwise transform features.

source
CausalTargeted.fit_covariate_schema — Function
fit_covariate_schema(df, covariates) -> CovariateSchema

Fit StatsModels terms for the requested covariates in their supplied order. Numeric and Boolean columns remain one column each. String and categorical columns use StatsModels' default DummyCoding, retaining the fitted levels and column order for later subsets or prediction data.

source
CausalTargeted.transform_covariates — Function
transform_covariates(schema, df) -> Matrix{Float64}

Encode df with the exact fitted terms, levels, contrasts, feature order, and matrix width stored in schema. Unseen levels produce an informative error.

CausalTargeted.design_matrix — Function
design_matrix(schema, df; treatment=nothing, treatment_values=nothing) -> Matrix{Float64}
