Discrete, hurdle, MSM & DiD

Discrete-treatment LMTP (Díaz–Williams classification density ratios), two-part hurdle LMTP, repeated-outcome and parametric marginal structural models (MSMs), mixed-model repeated measures (MMRM), and difference-in-differences (DiD).

Discrete runners default to capped classifier ratios and return point estimates. Their ordinary EIF standard errors, limits, and influence curves are unavailable with inference_status=:truncated_weights. Pass weight_truncation=false to use uncapped ratios and request EIF inference for supported policies; positivity, missingness, imputation, and targeting-status gates still apply.

CausalTargeted.run_discrete_lmtp — Function
run_discrete_lmtp(df, trt, outcome; policy, baseline, folds, rng, ...) -> NamedTuple

Point-treatment LMTP for a categorical exposure. Density ratios use the 2n classification construction of Díaz et al. (2021), with dummy-coded A. Gaussian location-scale ratios are rejected. Missing data follow the same handle_missing strategies as run_lmtp_grid. When cluster is set, folds keep clusters intact and intervals use a finite-cluster correction with G − 1 degrees of freedom. A failed positivity check leaves the point estimate available but marks its interval unavailable (NaN). The default finite ratio cap also leaves the point estimate available but reports :truncated_weights and unavailable EIF uncertainty. Set weight_truncation=false for uncapped ratios when finite-support policy inference is required; positivity, IPCW, and covariate-imputation gates still apply.

source
CausalTargeted.run_discrete_lmtp_contrast — Function
run_discrete_lmtp_contrast(
    df, trt, outcome;
    arm_hi, arm_ref, levels, kwargs...
) -> NamedTuple

Difference E[Y|do(arm_hi)] - E[Y|do(arm_ref)] from two static discrete LMTP policies. The standard error uses the row-aligned difference of their influence curves, preserving covariance between policy estimates. Each fold's outcome model is shared across both policies; policy-specific treatment models remain separate. Cluster intervals use G − 1 degrees of freedom. Finite default ratio caps gate EIF uncertainty; set weight_truncation=false for supported uncapped inference. Remaining kwargs are forwarded to run_discrete_lmtp.

CausalTargeted.bootstrap_discrete_lmtp_contrast — Function
bootstrap_discrete_lmtp_contrast(df, trt, outcome; B, rng, cluster, ...) -> NamedTuple

Percentile bootstrap CI for run_discrete_lmtp_contrast. Uses reduced folds inside replicates by default. Cluster resampling gives every sampled copy a fresh cluster ID. Only finite replicates with positivity supported both at the point fit and in the replicate count as successful. If fewer than max(2, ceil(min_success_fraction*B)) replicates succeed, the interval and bootstrap SE are NaN; the point estimate is retained and failures are reported.

Two-part hurdle LMTP

CausalTargeted.TwoPartInterventionalMean — Type
TwoPartInterventionalMean(trt, presence, intensity, adjustment, policy)

Hurdle estimand pairing a binary presence outcome with a continuous intensity outcome observed only when presence is positive. Presence is estimated with run_discrete_lmtp (family_outcome=:binomial); intensity is estimated on the subsample with observed positive intensity (conditional on $Y_{\mathrm{pres}} > 0$).

source
CausalTargeted.run_two_part_discrete_lmtp — Function
run_two_part_discrete_lmtp(
    df, trt;
    presence, intensity, policy, baseline, folds, rng, ...
) -> NamedTuple

Fit presence and conditional-intensity discrete LMTPs under one DiscreteTreatmentPolicy. The intensity part conditions on observed positive presence (presence > 0); the estimand is $E[Y_{\mathrm{int}} \mid Y_{\mathrm{pres}} > 0, \mathrm{do}(A)]$.

source
CausalTargeted.run_two_part_discrete_lmtp_contrast — Function
run_two_part_discrete_lmtp_contrast(
    df, trt;
    presence, intensity, arm_hi, arm_ref, levels, kwargs...
) -> NamedTuple

Arm contrast for a two-part hurdle outcome. Returns .presence and .intensity summaries (estimate, se, lower, upper, n). The intensity contrast is conditional on $Y_{\mathrm{pres}} > 0$ among rows retained after missing-data handling on the full panel. Each component uses the paired arm-score covariance; the intensity component remains a conditional positive-only contrast, not a marginal hurdle mean effect.

source
CausalTargeted.bootstrap_two_part_discrete_lmtp_contrast — Function
bootstrap_two_part_discrete_lmtp_contrast(df, trt; presence, intensity, ...) -> NamedTuple

Bootstrap summaries for presence and intensity arms of run_two_part_discrete_lmtp_contrast. Both parts use the same successful replicates; if the minimum success fraction is not met, returned bootstrap SEs and limits are NaN and the failure summary is retained. Replicates count as successful only when the point fit and both arms of both hurdle components satisfy positivity.

Repeated-outcome & parametric MSMs

CausalTargeted.RepeatedOutcomeMSM — Type
RepeatedOutcomeMSM(trt, outcomes, adjustment)

Point-treatment profile estimand: binary trt on several outcomes measured on the same units. Engine estimand_engine is :repeated_msm.

source
CausalTargeted.run_repeated_outcome_msm — Function
run_repeated_outcome_msm(df, treatment, outcomes; baseline, strata, propensity,
                         folds, learners, rng, handle_missing, estimator, cluster)
    -> NamedTuple

Estimate $\tau(t)$ for binary point treatment and several outcomes with a joint influence-function covariance.

Returns (estimates, se, covariance, ic, outcomes, n, positivity, missingness, …). Use msm_contrast for linear forms $c^\top\tau$ (e.g. $\tau(t_3)-\tau(t_2)$).

Missingness uses a shared sample across times (complete-profile $R$). estimator=:tmle (default) applies a per-fold clever-covariate fluctuation; :eif is the untargeted AIPW one-step.

strata may be one Symbol or a vector of symbols. Nuisance models are still fit on the full eligible sample, with these columns added to baseline, while targeting and Hajek standardisation are conditional on each joint stratum. propensity may be a known scalar, column symbol, or input-row-aligned vector; known values bypass treatment fitting but retain positivity diagnostics.

cluster may be a column Symbol in df or a length-nrow(df) id vector. When set, $\widehat{\Sigma}$ is cluster-robust (sampling hierarchy). This does not change the estimand to BLUP / partial pooling.

source

CausalTargeted.run_parametric_repeated_msm — Function
run_parametric_repeated_msm(df, treatment, outcomes; baseline, design, target, ...)
    -> NamedTuple

Estimate a parametric MSM by GLS projection of the unstructured repeated-outcome IF estimates from run_repeated_outcome_msm.

strata and propensity are passed through to the unstructured fit. A stratified projection requires an explicit K*T × p design for target=:tau or 2*K*T × p for target=:mean; symbolic T-row designs are rejected.

CausalTargeted.simulate_mean_treatment_time_msm — Function
simulate_mean_treatment_time_msm(n; T=3, β, β_w, ρ, σ_y, rng) -> (df, truth)

Binary treatment with outcomes whose conditional means follow a treatment×time MSM:

\[m(t,a)=\beta_0+\beta_A a+\sum_{t'\ge 2}\beta_{t'}I(t=t') +\sum_{t'\ge 2}\beta_{A t'} a\,I(t=t')\]

and $Y_t=m(t,A)+\beta_w W+\sigma_y(\sqrt{\rho}U+\sqrt{1-\rho}\varepsilon_t)$.

Default $\beta$ for $T=3$: $[1.0, 0.5, 0.2, 0.35, 0.15, 0.25]$. Truth includes beta, tau (implied ATE profile), and m.

Mixed-model repeated measures (MMRM)

Requires using MixedModels to load the CausalTargetedMixedModelsExt extension.

CausalTargeted.MMRMResult — Type
MMRMResult

Gaussian mixed model for repeated measures (MMRM) reference fit for a static treatment and repeated outcome visits.

Wraps a fitted MixedModels.LinearMixedModel and a MixedGComputationResult from run_mmrm. This is a parametric trial-style reference path beside LMTP/MSM; it is not a substitute for discrete longitudinal LMTP.

Fields

  • model: fitted LinearMixedModel
  • contrast: MixedGComputationResult (LS-mean-style trajectory contrast)
  • formula: applied MixedModels formula
  • covariance: :random_intercept or :unstructured (random-effects approximation)
  • time_categorical: whether :unstructured used an internal categorical visit factor
source
CausalTargeted.fit_mmrm — Function
fit_mmrm(
    data;
    outcome, treatment, time, id,
    baseline=Symbol[], covariance=:random_intercept
) -> LinearMixedModel

Fit a Gaussian MMRM with fixed effects outcome ~ treatment * time + baseline and a subject random-effects structure.

Covariance (covariance=)

  • :random_intercept — (1 | id) (default)
  • :unstructured — (1 + _mmrm_time | id) with an internal categorical visit column _mmrm_time (MixedModels random-effects approximation to unstructured within-subject correlation; not SAS/R mmrm residual $\Sigma$)

Random slopes are intentionally unsupported in this release; see issue #25.

Requires using MixedModels (loads CausalTargetedMixedModelsExt).

Fit an MMRM and return visit-specific contrast estimates via mixed_g_computation.

Difference-in-differences (DiD)

CausalTargeted.run_did_2x2 — Function
run_did_2x2(df; unit, time, treatment, outcome) -> NamedTuple

Classic 2×2 difference-in-differences estimator for panel data with two periods.

Assumes:

  • time column has exactly two values (sorted: pre, post)
  • treatment is time-invariant group indicator (0/1)
  • Parallel trends hold

Returns (att, se, ci_lower, ci_upper, n_treated, n_control).

source
CausalTargeted.run_did_staggered — Function
run_did_staggered(df; unit, time, treatment, outcome, cohort) -> DataFrame

Staggered difference-in-differences using cohort-time group ATTs.

For each treatment cohort, estimates ATT(g, t) for post-treatment periods using never-treated units as controls (Callaway–Sant'Anna style).

Returns a DataFrame with columns: cohort, time, att, se, n_treated, n_control.

source
CausalTargeted.aggregate_did — Function
aggregate_did(res::DataFrame) -> NamedTuple

Simple equal-weight ATT from staggered DiD results. When produced by run_did_staggered, the standard error uses its full unit-level influence covariance, including shared never-treated controls. Cell-only tables report unavailable uncertainty. independence_se retains the historical independence approximation as a diagnostic only.
