Parametric & Bayesian g-comp

Cross-fitted g-computation, formula-based parametric GLM and MixedModels g-computation (including dedicated subject-integrated NB2 random-intercept models), and conjugate or variational Bayesian g-computation.

fit_parametric_gcomp defaults to the GLM backend. Set backend=:mixed and provide id after loading MixedModels, FastGaussQuadrature, NLopt, and SpecialFunctions for supported mixed fits. See Methods and estimators for supported model, prediction, and inference combinations. Target data can omit the outcome; the repeated-outcome compatibility wrappers retain their existing static-treatment and observed-visit contract.

Cross-fitted & parametric GLM g-computation

CausalTargeted.run_gcomp — Function
run_gcomp(df, treatment, outcome; covariates, delta, folds, learners, rng, n_boot)
    -> NamedTuple

Cross-fitted plug-in g-computation for a binary or continuous treatment.

For binary treatment: estimates ATE = E[Q(1, W) - Q(0, W)]. For continuous treatment with delta: estimates E[Q(A + δ, W) - Q(A, W)] with A + δ clamped to the 1%–99% range of observed A.

estimator=:plugin (default), n_boot > 0 (default 200): percentile CI from a refitting bootstrap that redraws rows and recomputes the cross-fitted plug-in. For :ipcw, :impute, and :ipcw_impute, each draw resamples the original incomplete rows and reruns missing-data preprocessing, including imputation and response-model fitting; :drop resamples the complete-case analysis rows. n_boot = 0 returns NaN inferential SE/limits and uncertainty=:unavailable; prediction_se describes fitted-contrast variation only, excluding outcome-model estimation uncertainty.

estimator=:onestep estimates a binary 0/1 ATE using cross-fitted AIPW scores and their normal-Wald interval, with no bootstrap by default. Optional propensity is a known scalar or row-aligned vector of treatment probabilities; otherwise a cross-fitted logistic Super Learner is fitted. This route requires complete data and independent rows; continuous clamped shifts and missing-data corrections need different scores. Propensity truncation is reported and can introduce bias. Cross-fitting does not remove nuisance-rate or overlap assumptions.

Returns (estimate, se, ci_lower, ci_upper, n).

ParametricGComputationFit

A fitted parametric reference / complete-case GLM for empirical-distribution standardisation, separate from cross-fitted run_gcomp and LMTP estimators. covariance is coefficient covariance (HC3 by default). CausalTargeted.fit_parametric_gcomp — Function
fit_parametric_gcomp(formula, data; backend=:glm, family=:gaussian,
                     link=nothing, theta=nothing, covariance=nothing, kwargs...)

Fit a parametric outcome model for empirical-distribution g-computation, separate from cross-fitted run_gcomp and LMTP estimators. The default GLM backend supports Gaussian/identity, binomial/logit, Gamma/log, and negative-binomial/log (:negbin; aliases :negativebinomial, :negative_binomial, and :nb are normalised to :negbin). For GLM negative binomial, omit theta to estimate the NB2 shape continuously with GLM.negbin, or provide it for a fixed-shape fit. GLM coefficient covariance defaults to :hc3.

NB2 HC3 covariance and delta-method SEs/intervals treat theta as fixed at its supplied or estimated value; uncertainty in estimated theta is not propagated. Refit bootstraps re-estimate theta only when it was estimated in the original fit.

All outcome and predictor columns referenced by the formula must be present and contain no missing values. Handle missingness explicitly before fitting; this path never silently drops rows. Missing values in unrelated columns are allowed. Set backend=:mixed and supply id to use a supported Gaussian LMM or NB2 random-intercept model when the optional extension is loaded. A supplied NB2 theta selects the fixed-shape fit; omitting it selects the dedicated estimated-shape fitter. Mixed-model coefficient covariance defaults to :model. For nonlinear mixed predictions, pass random_effects=:zero or :marginal to the subsequent g-computation call.

CausalTargeted.gcomp_mean — Function
gcomp_mean(fit, data; set=(;), by=nothing, subset=nothing,

Standardise response-scale predictions over the empirical rows in data, or over the target rows selected by by/subset. Target rows are restricted before the intervention is applied. The target can differ from the training table in both rows and size and need not contain the outcome. Formula predictors in the selected target rows must be complete-case before intervention. CausalTargeted.bootstrap_gcomp_interaction — Function
bootstrap_gcomp_interaction(fit, data; n_boot=500, strata=nothing, ...)

Refit a non-parametric bootstrap for a formal interaction. If strata is provided, sampling occurs independently within each observed stratum and keeps the original stratum sizes. Failed fits are counted and summarised. The resampled table must be complete-case in the original formula's outcome and predictors. NB2 theta is re-estimated in each replicate if originally estimated; a supplied fixed theta stays fixed. This differs from HC3/delta intervals, which do not propagate theta-estimation uncertainty.

CausalTargeted.MixedGComputationResult — Type
MixedGComputationResult

Time-indexed standardised means and their contrast from mixed_g_computation.

mean_reference corresponds to values[1], mean_comparison to values[2], and effect is mean_comparison - mean_reference. adjustment records the graph-derived backdoor set when a graph was supplied. vcov is the joint fixed-effect covariance matrix of the effect trajectory, in times order, and se is sqrt.(diag(vcov)). random_effects records whether nonlinear-link predictions set random effects to zero (:zero) or integrate the response mean over a supported fitted Gaussian random-effects distribution (:marginal). This uncertainty is fixed-effect-only: it does not include residual, dispersion, or variance-component uncertainty. uncertainty is :delta_fixed or :parametric_bootstrap; the latter stores replicate counts, seed, failure messages, and successful trajectory draws in uncertainty_diagnostics.

CausalTargeted.mixed_g_computation — Function
mixed_g_computation(model, data; treatment, outcome, time, id,
                    values=(0, 1), strata=nothing, random_effects=:zero)
mixed_g_computation(graph, model, data; treatment, outcome, time, id,
                    values=(0, 1), strata=nothing, random_effects=:zero,
                    node_names=nothing)

Estimate a time-specific standardised contrast for a static treatment and a repeated outcome using a fitted MixedModels.LinearMixedModel or a supported MixedModels.GeneralizedLinearMixedModel.

The first method standardises population-level predictions under the two static interventions in values. With strata=nothing it returns one MixedGComputationResult. With a symbol or tuple of symbols, such as strata=:Age, it returns a StratifiedMixedGComputationResult whose trajectories are standardised over the remaining covariates within each stratum. The graph method first calls CausalDynamics identify for a TotalEffectQuery, requires backdoor identification, validates that the identified adjustment variables occur in the fitted formula, and records them in the returned MixedGComputationResult.

The estimand at each observed time t is

\[E_W[E(Y_t \mid A=\text{values}[2], W)] - E_W[E(Y_t \mid A=\text{values}[1], W)].\]

This compatibility front end uses the same counterfactual standardisation and contrast machinery as gcomp_mean and gcomp_contrast. It retains the repeated-outcome contract: treatment is static within id, times and strata follow their sorted observed order, and each visit is standardised over the rows actually observed at that visit. With unbalanced follow-up, visit estimates therefore refer to different empirical visit populations. The generic mixed interface does not require static treatment within its grouping factor.

This integration is provided by the optional MixedModels extension (CausalTargetedMixedModelsExt). It is a parametric reference path beside MSM / LMTP, not a silent substitute for run_repeated_outcome_msm. It supports Gaussian LinearMixedModels, fixed-shape NB2 negative-binomial GeneralizedLinearMixedModel compatibility fits, and dedicated NB2RandomInterceptModels that estimate shape. The model's grouping factor must be id. For random_effects=:zero, MixedModels prediction uses fresh ID levels with new_re_levels=:population, so fitted subject-specific random effects are set to zero. Gaussian identity-link predictions have the same population mean under :zero and :marginal, including supported random-coefficient models. For an NB2 random-intercept model, random_effects=:marginal applies the analytic Gaussian log-normal correction. The reported delta-method covariance conditions on all fitted or supplied variance components. Causal interpretation requires the usual identification assumptions and correct specification of the parametric outcome model.

Bayesian Gaussian g-computation

Fits a conjugate Gaussian outcome model or a one-level random-intercept Gaussian outcome model via structured variational inference $q(\beta, b) q(\sigma_\varepsilon^{-2}) q(\sigma_b^{-2})$ with exact Schur-complement block algebra and exact affine prior reparameterisation, integrating over the cluster random-effect distribution when evaluating marginal policy contrasts. Loading PSIS (using PSIS) activates CausalTargetedPSISExt for correction = :psis, which withholds intervals and covariance if operational gates (khat < 0.7, ess >= 400, mcse / sd <= 0.05) fail rather than falling back to raw VI. See Bayesian Gaussian & cluster for the non-clustered conjugate contract.

CausalTargeted.ConjugateGaussianPrior — Type
ConjugateGaussianPrior(; mean, covariance, shape, scale)

Explicit normal–inverse-gamma prior: β | σ² ~ Normal(mean, σ² * covariance) and σ² ~ InverseGamma(shape, scale). covariance is the conditional scale matrix, not the marginal covariance of β. Require positive definite covariance, shape > 1 and scale > 0, so marginal coefficient variances exist. No outcome-dependent rescaling is performed. With known observation variance, condition the normal prior on that variance; inverse-gamma parameters are unused.

source
CausalTargeted.BayesianGCompFit — Type

Exact coefficient posterior, fitted design, and assumptions for Gaussian g-computation.

posterior_scale is the Student-t scale matrix; posterior_covariance is its covariance. They coincide for known observation variance (posterior_df = Inf). Vn, shape, and scale retain the conjugate parameters. design_metadata records column order; variance_diagnostics reports prior and posterior marginal variances and their ratios. These ratios describe marginal contraction or expansion relative to the prior; sensitivity requires refitting under other priors. They do not establish causal identification or adequate model fit.

CausalTargeted.fit_bayesian_gcomp — Function
fit_bayesian_gcomp(data, outcome, treatment, covariates; prior,
    basis=nothing, identification=nothing, handle_missing=:error,
    observation_variance=nothing)

Fit a Gaussian outcome regression with an explicit conjugate prior. The default design is [intercept | treatment | covariates], with categorical dummy columns and their order retained by a single fitted CovariateSchema. Alternatively, basis(predictor_data, treatment_values) returns a matrix in a prespecified, unchanging column order, including any intercept and interactions. Only the treatment and declared covariate columns are passed to this function; the caller is responsible for keeping its transformations and column meanings unchanged.

Treatment and covariates must be fully observed and finite. Missing outcomes require handle_missing=:mar, explicitly recording user-assumed ignorable MAR; only observed outcomes enter the likelihood. Missing outcomes do not add information to the posterior. Without an identification certificate, causal identification is recorded as :user_assumed; a proper posterior is not a graph identification argument. A supplied certificate must certify the actual adjustment set, rather than a subset of additional regressors. graph_identification_status records that graph claim independently of the basis. outcome_model_status is always :user_assumed, including for the default linear basis: a graph certificate does not establish regression adequacy. The conservative summary identification_status remains :user_assumed for a user-supplied basis; the checked certificate and its graph status are retained.

Bayesian logistic g-computation

Non-clustered logistic regression (fit_bayesian_logistic) uses Jaakkola–Jordan variational inference with linear-response variance correction (LRVB); see Bayesian logistic (RxInfer). Clustered logistic regression (fit_bayesian_cluster_logistic) fits a one-level random-intercept Bernoulli–logit outcome model via Jaakkola–Jordan weighted Schur-complement structured VI $q(\beta, b) q(\sigma_b^{-2})$ (zero dense $N \times N$ or $K \times K$ allocations). Marginal policy contrasts integrate over $b_k \sim \mathrm{Normal}(0, \sigma_b^2)$ via 25-node Gauss–Hermite quadrature (distinct from setting b_k = 0). Optional correction = :psis uses a heavy-tailed Student-$t$ proposal on $(\beta, \log \sigma_b^2)$ with 21-node adaptive Laplace-centred 1D Gauss–Hermite marginalised cluster log-likelihoods and withholds intervals when operational gates fail.

CausalTargeted.fit_bayesian_logistic — Function
fit_bayesian_logistic(data, outcome, treatment, covariates; prior,
    basis=nothing, identification=nothing, handle_missing=:error,
    maxiter=1000, tol=1e-8, covariance=:linear_response)

Fit Bernoulli logistic regression with the optional RxInfer extension; load it with using RxInfer, GraphPPL. A proper coefficient prior must be specified. The default design and categorical levels are fitted once. A custom basis(predictor_data, treatment_values) receives only declared predictors and must preserve its column meanings. Missing predictors are rejected. Missing outcomes require explicit handle_missing=:mar; only observed outcomes enter the likelihood, under user-assumed ignorable MAR. With no observed outcomes, the coefficient posterior remains the specified prior.

The default maxiter=1000 allows more Jaakkola updates before withholding uncertainty; increase the cap if status === :maxiter. Standardising predictors while keeping the same coefficient prior changes the model. For coefficient order [intercept, treatment, W] and Wz = (W - c) / s, with s > 0, preserve the prior with T = [1 0 c; 0 1 0; 0 0 s], μz = T * μ and Vz = T * V * T'. Centring can introduce intercept-slope prior dependence. Apply the same declared transformation to fitting and target designs. This reparameterisation preserves logit second moments and does not guarantee fewer iterations.

Graph identification and outcome-model assumptions are recorded separately. A certificate does not certify a custom basis or regression adequacy. Neither variational moments nor linear-response corrections are exact posterior inference. Failed convergence or invalid requested correction withholds usable coefficient covariance; raw covariance is never silently substituted.

CausalTargeted.bayesian_policy_contrast — Function
bayesian_policy_contrast(fit, target, policy; deltas, level=0.95)

Exact joint posterior for the fixed-cohort :policy_vs_observed contrast. Each row of contrast_matrix averages design(policy(A)) - design(A) over the supplied target rows. The returned mean, covariance and scale retain cross-policy dependence. Intervals are pointwise equal-tailed credible intervals for a conditional mean contrast, without future-outcome noise. Supported policies are fixed-bound SmoothBoundedLogitShiftPolicy and DiscreteTreatmentPolicy; a discrete policy is independent of the grid labels in deltas. Its callback must be deterministic and is evaluated once for the target cohort. Both factual and assigned discrete levels must occur in the fitting data. Sample-clamped ShiftPolicy is rejected. No treatment density is estimated; causal interpretation requires identification, positivity and the specified outcome model, which a credible interval does not establish.

source
bayesian_policy_contrast(fit::BayesianLogisticFit, target, policy;
    deltas, level=0.95, n_draws=2000, mc_level=0.95, rng=Random.Xoshiro(42))

Approximate fixed-cohort posterior risk differences against observed treatment. One set of joint normal coefficient draws, using the selected fitted moments, is shared over the entire policy grid. Return Monte Carlo means, covariance, pointwise quantiles and mean MCSE. This normal moment approximation is an additional approximation: linear-response moments are not a corrected posterior density. No outcome noise or covariate-population sampling is added.

endpoint_mc_bounds gives pointwise Monte Carlo confidence bounds for each ideal Gaussian-law interval endpoint at confidence mc_level. Binomial order statistics of the existing independent draws provide these bounds; small draw counts can give the full risk-difference support [-1,1]. These bounds quantify endpoint simulation variability, not posterior approximation error, and are not simultaneous across endpoints or policies. mcse concerns means only.

Use fixed-bound smooth or discrete policies. A deterministic discrete callback is evaluated once per target row before drawing, independently of grid labels. Factual and assigned discrete levels must occur in the fitting data. When fitted uncertainty is unavailable, mean is the plug-in contrast at the coefficient mean, and covariance, intervals and MCSE are NaN.
