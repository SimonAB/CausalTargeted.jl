LMTP, sequential & survival

Continuous, sequential, and survival longitudinal modified treatment policy (LMTP) estimators implementing Díaz & van der Laan (2012) shifts and Díaz et al. (2023) LMTP variants (see Methods and estimators).

Continuous lmtp_tmle_contrast supports the uncapped influence-curve route only for Gaussian density ratios and constant additive shifts without clamping.

Continuous LMTP grids, contrasts & core TMLE

CausalTargeted.run_lmtp_grid — Function
run_lmtp_grid(data, trt, outcome; baseline, kwargs...) -> DataFrame

Cross-fitted SuperLearner LMTP TMLE grid matching R run_lmtp_grid() (shift_scale = "z").

Uses clamp-aware hybrid targeting: when many observations hit clamp bounds, the TMLE fluctuation is down-weighted toward g-computation.

Defaults:

  • density_ratio = :gaussian (stable at sheep n; use :hybrid / :classification for large n)
  • cv_trunc = false (prespecified trunc; opt-in variance heuristic is not cross-validation)
  • estimator = :tmle (score-solving; pass :sdr / :eif / :itmle as needed)
  • epochs = 1 (do not inherit mediation-grid epochs=30)
  • simultaneous = true adds multiplier-bootstrap simultaneous bands
  • parallel = true when Threads.nthreads() > 1
  • cache_nuisances = true reuses fold outcome / exposure models across δ

Quantile clamping creates boundary masses under a continuous treatment law, so ordinary nonparametric EIF intervals are unavailable for nonzero hard-clamped shifts. Use smooth_bounded_logit_shift_policy(L, U) for a distinct smooth, invertible policy with EIF intervals; bounds must be fixed in advance and uncapped Gaussian ratios are required for those intervals.

CausalTargeted.run_lmtp_contrast — Function
run_lmtp_contrast(data, trt, outcome; baseline, q_hi, q_lo, folds, rng) -> NamedTuple

LMTP TMLE contrast: fixed exposure at q_hi vs q_lo quantiles (antibodies / AUC notebooks). For continuous treatment, these point interventions do not have an ordinary nonparametric EIF. Point estimates are retained, but inferential SEs and limits are unavailable; use a justified parametric standardisation model for inference.

CausalTargeted.lmtp_tmle_contrast — Function
lmtp_tmle_contrast(...) -> NamedTuple

estimator:

  • :tmle (default) — score-solving separate-policy TMLE
  • :eif / :aipw / :sdr — full EIF one-step P_n[Q(d)+H(Y−Q)] (SDR at T = 1)
  • :itmle — compatibility label for the same canonical weighted-intercept targeting step

density_ratio: :gaussian (default), :classification, or :hybrid.

cv_trunc=true selects the hard truncation among trunc_candidates by clever-covariate variance. targeting_weight scales fluctuations toward g-computation. epochs remains available for compatibility; each arm's canonical score is solved in one step.

CausalTargeted.lmtp_tmle_policy_mean — Function
lmtp_tmle_policy_mean(...) -> (psi, ic)

Single-policy interventional mean under the supplied treatment policy. :tmle and :itmle use the canonical weighted-intercept update; :eif, :aipw, and :sdr use the initial one-step score. The centred influence curve is all NaN when fixed weight truncation or another unsupported route gates inference. An identity policy returns the natural sample mean and its centred outcome values.

smooth_bounded_logit_shift_policy(lower, upper)

Sequential & survival LMTP

CausalTargeted.SequentialPolicy — Type
SequentialPolicy(treatments, outcome, baseline; time_vary, shift, policies)

Time-ordered treatments A_1,…,A_T, baseline covariates L_0, and optional time-varying covariates time_vary[t] observed before A_t.

Empty policies selects the numeric additive-shift path. A nonempty vector of DiscreteTreatmentPolicy (length T, or length 1 broadcast to every time) selects dummy-coded factor recodes. Mixed continuous and categorical A_t is not supported.

source
CausalTargeted.run_sequential_lmtp — Function
run_sequential_lmtp(data, treatments, outcome; baseline, time_vary, delta, folds, learners, rng) -> NamedTuple

Recursive g-computation + a cross-fitted sequential one-step score for discrete policies. Numeric exposures share an additive MTP shift delta and retain the existing point estimate, with inference marked unsupported for quantile clamping. Categorical exposures require policies (DiscreteTreatmentPolicy per time, or one policy broadcast to all times). Discrete policy functions receive the baseline covariate context W0; the time-specific density-ratio models condition on the pre-treatment history H_t.

Returns estimate, se, Wald limits, and inference_status. Discrete policies also return per-time density-ratio diagnostics, positivity, and n_changed.

CausalTargeted.run_survival_lmtp — Function
run_survival_lmtp(data, treatments, surv; baseline, time_vary, censor, delta, horizon, ...) -> NamedTuple

Sequential regression estimator of event-free probability at horizon under a common MTP shift delta on every treatment time through the horizon.

handle_missing applies to MAR / MCAR missingness in the terminal event-free indicator surv[horizon] (and covariates), via handle_missing_data. That is not the same as survival censoring IPCW: pass censoring indicators in censor so _censor_ipcw reweights the observed risk set. Do not encode right-censoring by setting S_T to missing and hoping :ipcw replaces censoring weights.

Returns a NamedTuple including estimate, se, n, times, horizon, delta, estimand=:survival, inference_status, and missingness metadata. The current quantile-clamped continuous shift retains its point estimate but does not have a reported standard error or interval under the dominated-law EIF.
