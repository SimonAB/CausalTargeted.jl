LMTP, sequential & survival

Continuous, sequential, and survival longitudinal modified treatment policy (LMTP) estimators implementing Díaz & van der Laan (2012) shifts and Díaz et al. (2023) LMTP variants (see Methods and estimators).

Continuous lmtp_tmle_contrast uses Gaussian density ratios for uncapped influence-curve inference with constant additive, smooth bounded logit, feasible additive, and proportional headroom shifts.

For fixed SD shifts on an already standardised exposure, use feasible_additive_shift_policy(L, U; sd_scale=1) as the policy argument to run_lmtp_grid with weight_truncation=false. On the original scale, supply a prespecified SD in the exposure's units. The grid reports effective_shift in the exposure's units. Bounds determine eligibility for the shift. Inference still relies on overlap conditional on covariates.

For a deterministic, raw-scale, range-adaptive contraction without boundary clamping, use proportional_headroom_policy(L, U) with grid values delta in (-1, 1) and weight_truncation=false. Each exposure in [L, U] moves by a fraction delta of its remaining headroom toward U (when delta >= 0) or abs(delta) toward L (when delta < 0); exposures outside [L, U] remain unchanged. The policy induces a single-branch Gaussian density ratio with Jacobian $1 / (1 - |\delta|)$ on its image.

For a stochastic exponential-tilting intervention that remains well-conditioned under weak overlap without ad-hoc weight truncation, use exponential_tilt_policy(; bound = 2.0, center = 0.0) with estimate_exponential_tilt or as the policy argument to run_lmtp_grid. Setting bound = M > 0 defines the smooth tilt score $\phi(a) = M \tanh((a - c) / M)$, guaranteeing density-ratio bounds $\exp(-2|\delta|M) \le H_\delta(A, W) \le \exp(2|\delta|M)$ almost surely. Normalisers $\log m_0(W)$ are fitted by strictly convex calibration balancing, outcome targeting reuses canonical-link TMLE, and dual-axis EIF inference reports both the outcome contrast $\tau(\delta)$ and the realised exposure shift $\Delta(\delta)$ with Wald and studentised multiplier bootstrap intervals (studentised_multiplier_ci).

Continuous LMTP grids, contrasts & core TMLE

CausalTargeted.run_lmtp_grid — Function
run_lmtp_grid(data, trt, outcome; baseline, kwargs...) -> DataFrame

Cross-fitted SuperLearner LMTP TMLE grid matching R run_lmtp_grid() (shift_scale = "z").

Uses clamp-aware hybrid targeting: when many observations hit clamp bounds, the TMLE fluctuation is down-weighted toward g-computation.

Defaults:

  • density_ratio = :gaussian (stable at sheep n; use :hybrid / :classification for large n)
  • cv_trunc = false (prespecified trunc; opt-in variance heuristic is not cross-validation)
  • estimator = :tmle (score-solving; pass :sdr / :eif / :itmle as needed)
  • epochs = 1 (do not inherit mediation-grid epochs=30)
  • simultaneous = true adds multiplier-bootstrap simultaneous bands
  • parallel = true when Threads.nthreads() > 1
  • cache_nuisances = true reuses fold outcome / exposure models across δ

Quantile clamping creates boundary masses under a continuous treatment law, so ordinary nonparametric EIF intervals are unavailable for nonzero hard-clamped shifts. Use smooth_bounded_logit_shift_policy(L, U) for a distinct smooth, invertible policy with EIF intervals; bounds must be fixed in advance and uncapped Gaussian ratios are required for those intervals.

Use feasible_additive_shift_policy(L, U; sd_scale) to interpret the grid values in fixed SD units. This policy retains scores whose proposed shift falls outside the bounds. It uses Gaussian density ratios, with both preimages included where the shifted and retained branches overlap.

Use proportional_headroom_policy(L, U) for a deterministic, range-adaptive contraction on prespecified bounds [L, U] with grid values delta in (-1, 1). Positive shifts move each exposure in [L, U] by a proportion delta of its remaining headroom toward U, and negative shifts move by abs(delta) of remaining headroom toward L, without boundary clamping. It uses exact single-branch Gaussian density ratios and provides uncapped EIF intervals with weight_truncation=false.

Use exponential_tilt_policy(; bound = 2.0, center = 0.0) for a stochastic exponential-tilting intervention $g_\delta(a \mid W) \propto \exp(\delta \phi(a)) g(a \mid W)$ with calibration-balanced TMLE (Díaz & Hejazi 2020; Schindl, Shen & Kennedy 2024). When bound = M > 0, $\phi(a) = M \tanh((a - c) / M)$ automatically bounds the density ratio in $[\exp(-2|\delta|M), \exp(2|\delta|M)]$ without ad-hoc weight truncation; effective_shift reports the estimated realised shift $\hat{\Delta}(\delta)$.

CausalTargeted.estimate_exponential_tilt — Function
estimate_exponential_tilt(df, trt, outcome, covariates, delta, policy; kwargs...) -> NamedTuple

Cross-fitted calibration-balanced TMLE for an exponential-tilting stochastic intervention $g_\delta(a \mid W) \propto \exp(\delta \phi(a)) g(a \mid W)$.

Estimates both:

  • Outcome contrast $\tau(\delta) = \psi(\delta) - \mathbb{E}[Y]$ with canonical-link TMLE targeting via CausalTargeted._weighted_intercept_tilt and exact EIF $\varphi_\delta(O) = H_\delta(A, W)(Y - \theta^*_\delta(W)) + \theta^*_\delta(W) - Y - \hat{\tau}(\delta)$.
  • Realised mean exposure shift $\Delta(\delta) = \mathbb{E}_{g_\delta}[A] - \mathbb{E}[A]$ with the matching Gaussian EIF.

Returns both Wald CIs (lower, upper) and studentised multiplier bootstrap CIs (boot_lower, boot_upper), alongside weight ESS and TMLE score diagnostics.

Keyword arguments

  • family_outcome::Symbol = :gaussian: :gaussian, :binomial, :poisson, or :negbin.
  • folds::Int = 5: number of cross-fitting folds (automatically capped to n ÷ 2 if needed).
  • independent_folds::Bool = true: use separate cross-fit partitions for $\hat{m}_0(W)$ and $\hat{\theta}_\delta(W)$ to attenuate finite-sample correlation in the second-order DR remainder (Newey & Robins 2018); set false for a single shared partition.
  • lambda::Real = 0.0: optional L2 ridge penalty on standardised non-intercept normaliser coefficients.
  • outcome_method::Symbol = :plugin: :plugin (two-stage Rao-Blackwellised), :plugin_poisson, or :direct.
  • enforce_bounds::Bool = true: project bounded-policy $\log \hat{m}_0(W)$ onto $[-|\delta|M, |\delta|M]$.
  • normalizer_covariates = covariates: override covariate columns used for $\hat{m}_0(W)$ (e.g. for DR tests).
  • outcome_covariates = covariates: override covariate columns used for $\hat{\theta}_\delta(W)$ (e.g. for DR tests).
  • alpha::Real = 0.05: two-sided significance level.
  • bootstrap_B::Int = 999: replicates for studentised multiplier bootstrap.
  • bootstrap_weights::Symbol = :rademacher: :rademacher (default) or :mammen.
  • rng::AbstractRNG = StableRNG(2026): RNG for cross-fitting and multiplier bootstrap.

CausalTargeted.proportional_headroom_policy — Function
proportional_headroom_policy(lower, upper)

Construct a deterministic, range-adaptive contraction policy on the prespecified interval [lower, upper]. For a proportion delta in (-1, 1) and an exposure a in [lower, upper]:

  • delta >= 0: a + delta * (upper - a) (moves a fraction delta of remaining headroom toward upper)
  • delta < 0: a + abs(delta) * (lower - a) (moves a fraction abs(delta) of remaining headroom toward lower)

Exposures outside [lower, upper] or outside stratum_mask are retained unchanged. Bounds must be fixed before analysing the sample.

source
CausalTargeted.ExponentialTiltPolicy — Type
ExponentialTiltPolicy(; bound = nothing, center = 0.0)

Stochastic exponential-tilting intervention policy with score function:

  • Unbounded (bound = nothing): $\phi(a) = a - c$
  • Bounded (bound = M > 0): $\phi(a) = M \tanh((a - c) / M)$

The tilt weight is $w_\delta(a) = \exp(\delta \phi(a))$. For bound = M, $|\phi(a)| \le M$, so $\exp(-2|\delta|M) \le w_\delta(A) / m_0(W) \le \exp(2|\delta|M)$ almost surely without ad-hoc truncation.

CausalTargeted.studentised_multiplier_ci — Function
studentised_multiplier_ci(estimate, ic; alpha = 0.05, B = 999, weights = :rademacher, rng = StableRNG(2026))

Compute a studentised multiplier (wild) bootstrap confidence interval for an asymptotically linear estimator with influence function vector ic (mean zero).

For each bootstrap draw $b = 1, \dots, B$:

  1. Draw i.i.d. multipliers $\xi_i^{(b)}$ (:rademacher on $\{-1, +1\}$, default, or :mammen two-point distribution matching $\mathbb{E}[\xi]=0, \mathbb{E}[\xi^2]=1, \mathbb{E}[\xi^3]=1$).
  2. Form $z_i^{(b)} = \xi_i^{(b)} \hat{\varphi}_i$, bootstrap shift $\bar{z}^{(b)} = \frac{1}{n}\sum_i z_i^{(b)}$, and bootstrap SE $\widehat{\mathrm{SE}}^{(b)} = \mathrm{sd}(z^{(b)}) / \sqrt{n}$.
  3. Studentise $T^{(b)} = \bar{z}^{(b)} / \widehat{\mathrm{SE}}^{(b)}$.
  4. Invert quantiles $[q_{\alpha/2}, q_{1-\alpha/2}]$: $[\hat{\tau} - q_{1-\alpha/2} \widehat{\mathrm{SE}},\; \hat{\tau} - q_{\alpha/2} \widehat{\mathrm{SE}}]$.

:rademacher is the default because $\xi_i^2 \equiv 1$ yields strictly heavier-than-normal $t$-like finite-sample quantiles, whereas :mammen satisfies $\xi_i^2 = \xi_i + 1$ so large positive draws inflate $\widehat{\mathrm{SE}}^{(b)}$ and can compress the lower bound in small samples.

CausalTargeted.run_sequential_lmtp — Function
run_sequential_lmtp(data, treatments, outcome; baseline, time_vary, delta, folds, learners, rng) -> NamedTuple

Recursive g-computation + a cross-fitted sequential one-step score for discrete policies.
