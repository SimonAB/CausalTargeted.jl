Getting started

CausalTargeted estimates LMTP and related interventional targets once CausalDynamics.jl has supplied a graph and adjustment set. The walk-throughs below run end to end in Documenter (synthetic data, small folds) so you can copy the pattern onto cohort tables.

Install from General, or develop a local clone:

using Pkg
Pkg.add("CausalTargeted")  # resolves CausalDynamics from General
# Pkg.develop(path="<path-to-local-clone>")  # e.g. after git clone

Load plotting backends when you want figures:

using CausalTargeted, CausalDynamics, Graphs, DAGMakie, CairoMakie

Mediation examples additionally need using CausalMediation.

Each walk-through below plots DAGs in the style of Cinelli, Forney & Pearl (2024, SMR): a good-control triangle (dagplot_confounding) for total-effect identification, a full mediation DAG (with M on causal paths) for mediation identification, then the estimand path (dagplot_chain or dagplot_mediation) with structural_edge_labels on edges where needed. Custom dagplot layouts use edge_routing / CurvedEdge on skip chords (see CausalMediation Getting started).

Papers implemented in each section are named at the section opening; the full map is in Methods and References.

1. Identify, then estimate a δ-grid (LMTP)

Implements continuous MTP / LMTP point-treatment grids of Díaz et al. (2023, JASA), with stochastic-shift roots in Díaz & van der Laan (2012, Biometrics). R companion: Williams & Díaz (2023, Observational Studies).

Graph. Baseline confounding of a continuous exposure (W → A → Y, W → Y).

using CausalTargeted, CausalDynamics, Graphs, StableRNGs

g = DiGraph(3)
add_edge!(g, 1, 2)  # W → A
add_edge!(g, 1, 3)  # W → Y
add_edge!(g, 2, 3)  # A → Y
names = Dict(1 => :W, 2 => :A, 3 => :Y)

id = identify(g, TotalEffectQuery(:A, :Y); node_names = names)
id.identifiable, id.adjustment, id.strategy
(true, [:W], :backdoor)

Graph (identification). Good-control triangle: W is adjusted; paths carry no estimates.

    exposure = 2,
    outcome = 3,
    adjustment = Set([1]),  # good control W (Cinelli et al. 2024)

For an unclamped, constant additive Gaussian shift, the direct contrast helper also offers an uncapped ratio route with EIF-based uncertainty. This route requires density_ratio=:gaussian and the same constant additive shift for both policy vectors:

using CausalTargeted, StableRNGs

data, _ = simulate_linear_mtp(300; rng = StableRNG(14))
a0 = copy(data.A)
a1 = data.A .+ 0.5
fit = lmtp_tmle_contrast(
    data, :A, :Y, [:W], a1, a0, 3, StableRNG(15);
    density_ratio = :gaussian,
    weight_truncation = false,
)
(fit.estimate, fit.se, fit.inference_status)
(0.2742893572880391, 0.011573664673835776, :available)

The default keeps capped point estimates but marks their ordinary EIF intervals unavailable. The uncapped route removes the package-level ratio cap; learner-specific probability guards can still apply. Clamped policies and attenuated targeting do not acquire ordinary EIF coverage merely by returning finite numbers.

3. Interventional mediation (CausalMediation)

Implements interventional / stochastic mediation contrasts of Díaz & Hejazi (2020, JRSS-B), Hejazi et al. (2023, Biostatistics), and Liu et al. (2024, arXiv:2408.14620). Estimation lives in CausalMediation.jl; CausalTargeted supplies nuisances and optional façades once the weak dependency is loaded.

using CausalMediation, CausalTargeted, CausalDynamics, Graphs, StableRNGs

g = DiGraph(4)
add_edge!(g, 1, 2); add_edge!(g, 1, 3); add_edge!(g, 1, 4)
add_edge!(g, 2, 3); add_edge!(g, 2, 4); add_edge!(g, 3, 4)
names = Dict(1 => :W, 2 => :A, 3 => :M, 4 => :Y)

id = identify(
    g, MediationQuery(:A, :Y, [:M]; effect_kind = :interventional);
    node_names = names,
)
spec = spec_from_identification(id)

df, _ = simulate_continuous_mtp_mediation(200; rng = StableRNG(7))
res = run_mediation(
    spec, df;
    deltas = [0.5],
    folds = 2,
    n_mc = 16,
    estimator = :onestep,
    learners = DEFAULT_SL_LEARNERS,
    parallel = false,
    rng = StableRNG(8),
)
d = decompose(res)
d
(te = 0.3003748139168566, nde = 0.10327575795693239, nie = 0.19709905595992425)

4. Sequential LMTP

Implements the longitudinal MTP identification and sequential regression / TMLE strategy of Díaz et al. (2023, JASA).

Two time points with a time-varying covariate (L1 between A1 and A2):

using CausalTargeted, CausalDynamics, StableRNGs, DataFrames

rng = StableRNG(9)
n = 80
W = randn(rng, n)
A1 = 0.5 .* W .+ randn(rng, n)
L1 = 0.3 .* A1 .+ randn(rng, n)
A2 = 0.4 .* L1 .+ 0.2 .* W .+ randn(rng, n)
Y = 0.5 .* A2 .+ 0.3 .* A1 .+ 0.2 .* W .+ randn(rng, n)
df = DataFrame(W = W, A1 = A1, L1 = L1, A2 = A2, Y = Y)

res = run_sequential_lmtp(
    df, [:A1, :A2], :Y;
    baseline = [:W],
    time_vary = [Symbol[], [:L1]],
    delta = 0.5,
    folds = 2,
    learners = SMALL_N_SL_LEARNERS,
    rng = rng,
)
res.estimate, res.times
(0.5051842179120768, 2)

With a temporal DAG in CausalDynamics, attach a certificate before estimating. The compact TemporalDAGSpec(variables, edges) form remains valid (default PointwiseSupport). Declare TemporalNodeSpec(...; temporal_support = FromOnsetSupport(onset)) when an attribute should not unroll per time (see CausalDynamics #29). Support fixes node count; optional occasion / enduring character is a separate ReferentSpec declaration and never selects how many nodes appear.

using CausalDynamics: TemporalDAGSpec, LaggedEdge, unroll_temporal_dag, TemporalEffectQuery

spec = TemporalDAGSpec([:w, :a, :l, :y], [
    LaggedEdge(:w, :a, 0),
    LaggedEdge(:a, :l, 0),
    LaggedEdge(:l, :a, 1),
    LaggedEdge(:a, :y, 0),
    LaggedEdge(:a, :y, 1),  # A₁ → Y (matches synthetic DGP)
    LaggedEdge(:w, :y, 0),
])
u = unroll_temporal_dag(spec, 2)
tq = TemporalEffectQuery(:a, :y, 1, 2)
cert = sequential_identification_certificate(u, tq)
cert.result.strategy, cert.temporal_lags
(:temporal_backdoor, (treat_lag = 1, outcome_lag = 2))

9. Discrete and categorical treatments

Implements classification density-ratio LMTP for finite-support treatments (Díaz et al., 2023; Williams & Díaz, 2023). Here a baseline confounder W (such as host body mass) affects both assignment to a three-level treatment ("control", "low", "high") and an outcome Y. Passing weight_truncation = false requests uncapped EIF inference for static arms.

using CausalTargeted, DataFrames, StableRNGs

rng = StableRNG(91)
n = 240
W = randn(rng, n)
u = rand(rng, n)
p_low = 1.0 ./ (1.0 .+ exp.(-0.5 .* W))
A = [u[i] < 0.35 ? "control" : (u[i] < 0.35 + 0.35 * p_low[i] ? "low" : "high") for i in 1:n]
effect_a = [a == "control" ? 0.0 : (a == "low" ? 0.6 : 1.3) for a in A]
Y = 1.0 .+ 0.5 .* W .+ effect_a .+ 0.4 .* randn(rng, n)
df_cat = DataFrame(W = W, A = A, Y = Y)

res_cat = run_discrete_lmtp_contrast(
    df_cat, :A, :Y;
    arm_hi = "high",
    arm_ref = "control",
    levels = ["control", "low", "high"],
    baseline = [:W],
    folds = 2,
    learners_outcome = SMALL_N_SL_LEARNERS,
    weight_truncation = false,
    rng = StableRNG(92),
)

(
    estimate = round(res_cat.estimate; digits = 3),
    se = round(res_cat.se; digits = 3),
    status = res_cat.inference_status,
)
(estimate = 1.307, se = 0.065, status = :available)

10. Two-part / hurdle biological outcomes

Many ecological and parasitological outcomes are zero-inflated: an individual is either uninfected (infected = 0) or infected (infected = 1) with a positive intensity (log_eggs). run_two_part_discrete_lmtp_contrast estimates the presence contrast on the full cohort and the conditional positive-only intensity contrast among infected rows using paired arm-score covariance.

using CausalTargeted, DataFrames, StableRNGs

rng = StableRNG(101)
n = 260
W = randn(rng, n)
p_trt = 1.0 ./ (1.0 .+ exp.(-0.4 .* W))
A = [rand(rng) < p_trt[i] ? "treated" : "control" for i in 1:n]
p_inf = [1.0 / (1.0 + exp(-(0.4 + 0.5 * W[i] - (A[i] == "treated" ? 0.9 : 0.0)))) for i in 1:n]
infected = [rand(rng) < p_inf[i] ? 1.0 : 0.0 for i in 1:n]
log_eggs = [
    infected[i] == 1.0 ? (2.0 + 0.4 * W[i] - (A[i] == "treated" ? 0.6 : 0.0) + 0.3 * randn(rng)) : 0.0
    for i in 1:n
]
df_hurdle = DataFrame(W = W, A = A, infected = infected, log_eggs = log_eggs)

res_h = run_two_part_discrete_lmtp_contrast(
    df_hurdle, :A;
    presence = :infected,
    intensity = :log_eggs,
    arm_hi = "treated",
    arm_ref = "control",
    levels = ["control", "treated"],
    baseline = [:W],
    folds = 2,
    learners_outcome = SMALL_N_SL_LEARNERS,
    weight_truncation = false,
    rng = StableRNG(102),
)

(
    presence_diff = round(res_h.presence.estimate; digits = 3),
    intensity_diff = round(res_h.intensity.estimate; digits = 3),
)
(presence_diff = -0.223, intensity_diff = -0.578)

11. Discrete-time survival (run_survival_lmtp)

Implements discrete-time event-free survival estimation under a longitudinal modified treatment policy (Díaz, Hoffman & Hejazi, 2024; competing risks deferred). Each wave records a continuous exposure (A1, A2) and an event-free indicator (S1, S2, where 1 means still alive).

using CausalTargeted, DataFrames, StableRNGs

rng = StableRNG(111)
n = 220
W = randn(rng, n)
A1 = 0.4 .* W .+ randn(rng, n)
p_s1 = 1.0 ./ (1.0 .+ exp.(-(1.2 .+ 0.3 .* W .+ 0.5 .* A1)))
S1 = Float64.(rand(rng, n) .< p_s1)
A2 = 0.5 .* A1 .+ 0.3 .* W .+ randn(rng, n)
p_s2 = 1.0 ./ (1.0 .+ exp.(-(1.0 .+ 0.3 .* W .+ 0.5 .* A2)))
S2 = S1 .* Float64.(rand(rng, n) .< p_s2)
df_surv = DataFrame(W = W, A1 = A1, S1 = S1, A2 = A2, S2 = S2)

res_s0 = run_survival_lmtp(
    df_surv, [:A1, :A2], [:S1, :S2];
    baseline = [:W], delta = 0.0, folds = 2,
    learners = SMALL_N_SL_LEARNERS, rng = StableRNG(112),
)
res_s1 = run_survival_lmtp(
    df_surv, [:A1, :A2], [:S1, :S2];
    baseline = [:W], delta = 0.5, folds = 2,
    learners = SMALL_N_SL_LEARNERS, rng = StableRNG(112),
)

(
    surv_natural = round(res_s0.estimate; digits = 3),
    surv_shifted = round(res_s1.estimate; digits = 3),
)
(surv_natural = 0.579, surv_shifted = 0.633)

12. Multiplicative and threshold shift policies

Beyond additive shifts, CausalTargeted provides multiplicative scaling (multiplicative_shift_policy) and threshold policies (threshold_shift_policy, "raise exposure to at least c") for realistic biological interventions (Díaz & van der Laan, 2012; Díaz et al., 2023).

using CausalTargeted

a = [0.4, 0.8, 1.2, 1.8, 2.5]
pol_mult = multiplicative_shift_policy()
pol_thr = threshold_shift_policy()

(
    original = a,
    scaled_down_20pct = round.(apply_policy_values(a, -0.2, pol_mult); digits = 2),
    threshold_bump_below_median = round.(apply_policy_values(a, 0.5, pol_thr); digits = 2),
)
(original = [0.4, 0.8, 1.2, 1.8, 2.5], scaled_down_20pct = [0.42, 0.64, 0.96, 1.44, 2.0], threshold_bump_below_median = [0.81, 1.21, 1.2, 1.8, 2.47])

13. Hierarchical Bayesian g-computation (clustered units)

When biological units are grouped in cages, pens, litters, or clinics and sample sizes are small, fit_bayesian_cluster_gcomp fits a one-level random-intercept Gaussian model via structured variational inference and evaluates marginal policy contrasts with bayesian_policy_contrast. See also Bayesian Gaussian estimation and Bayesian logistic estimation.

using CausalTargeted, DataFrames, LinearAlgebra, StableRNGs

rng = StableRNG(131)
n_clusters, per_cluster = 12, 8
n = n_clusters * per_cluster
cage = repeat(1:n_clusters, inner = per_cluster)
b_cage = 0.6 .* randn(rng, n_clusters)
W = randn(rng, n)
A = [rand(rng) < (1.0 / (1.0 + exp(-0.3 * W[i]))) ? "treated" : "control" for i in 1:n]
Y = 1.5 .+ 0.7 .* (A .== "treated") .+ 0.4 .* W .+ b_cage[cage] .+ 0.5 .* randn(rng, n)
df_cl = DataFrame(cage = cage, W = W, A = A, Y = Y)

# Design has intercept + treatment indicator + W (3 parameters)
prior = ClusterGaussianPrior(;
    mean = zeros(3),
    covariance = Matrix(4.0 * I, 3, 3),
    residual_shape = 2.0,
    residual_scale = 1.0,
    cluster_shape = 2.0,
    cluster_scale = 1.0,
)

fit = fit_bayesian_cluster_gcomp(df_cl, :Y, :A, [:W]; cluster = :cage, prior = prior)
pol_hi = discrete_static_policy("treated"; levels = ["control", "treated"])
pol_lo = discrete_static_policy("control"; levels = ["control", "treated"])

c_hi = bayesian_policy_contrast(fit, df_cl, pol_hi; deltas = [1.0], n_draws = 500, rng = StableRNG(132))
c_lo = bayesian_policy_contrast(fit, df_cl, pol_lo; deltas = [1.0], n_draws = 500, rng = StableRNG(132))
(
    status = fit.status,
    shift_vs_obs_treated = round(c_hi.mean[1]; digits = 3),
    shift_vs_obs_control = round(c_lo.mean[1]; digits = 3),
)
(status = :converged, shift_vs_obs_treated = 0.354, shift_vs_obs_control = -0.326)
